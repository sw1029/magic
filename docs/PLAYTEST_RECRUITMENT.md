## 공지문

**[게임 플레이테스트 참가자 모집] 마우스로 직접 마법진을 그리는 퍼즐 게임**

직접 만든 2D 퍼즐 게임 **Magic Exam Hall**의 플레이테스트 참가자를 모집합니다.

- **게임 소개**: 떠 있는 마법탑의 입학생이 되어, 맵 바닥에 마우스로 직접 문양을 그려 마법을 시전하고 5층 시험을 통과하는 게임입니다. 정답을 외우는 게임이 아니라 직접 실험하며 발견하는 게임입니다.
- **하는 일**: 게임을 처음부터 엔딩까지 플레이(최대 60분) + 짧은 설문과 인터뷰(약 15분)
- **소요 시간**: 총 75분 내외
- **장소/방식**: (대면: 장소 기입 / 원격: 빌드 전달 + 화면 공유)
- **필요 조건**: 마우스 사용이 가능한 분. 게임 경험 무관 — **게임을 잘 못해도 전혀 상관없습니다** (오히려 처음 보는 분의 반응이 가장 중요합니다)
- **참가 보상**: (기입: 음료/기프티콘 등)
- **모집 인원**: 5명 (파일럿 1명 별도)
- **개인정보**: 플레이 기록은 익명으로 수집되며 실명·연락처는 기록하지 않습니다. 자세한 기준은 연구 문서(LOGGING_AND_PRIVACY)를 따릅니다.

## 진행자 체크리스트 (세션당)

1. [ ] `playtest-1` 태그 빌드 준비, 로그 폴더 비우기
2. [ ] 참가자 그룹 배정 (입력 버퍼 0.6/0.8/1.0초 — RESEARCH_PROTOCOL의 A/B 배정표)
3. [ ] 동의 안내 (익명 로그 수집) 후 시작
4. [ ] 관찰표 기록: 첫 시전까지 시간, 층별 막힘 지점, 발화
5. [ ] 종료 후 설문 + 인터뷰 15분 ("실패했을 때 무엇을 고치면 될지 알 수 있었나요?")
6. [ ] 로그(`attempts.*`, `survey.*`) 수거 → `outputs/playtest-1/` 익명화 저장

## 일정 잡기

- 파일럿 1인을 먼저 진행하고 프로토콜 결함을 수정한 뒤 본 테스트 5인을 진행한다.
- 본 테스트는 한 명씩, 세션 간 30분 여유를 둔다 (로그 수거·리셋 시간).
